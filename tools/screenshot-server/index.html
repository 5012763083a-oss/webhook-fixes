Screenshot server

A self-hosted Playwright CLI and HTTP server: GET /screenshot?url= returns a PNG.

npx screenshot serve
curl 'http://127.0.0.1:3000/screenshot?url=https://example.com' -o shot.png
  • Binds 127.0.0.1 by default; optional API_KEY via the x-api-key header
  • Blocks private, loopback and link-local addresses; resolves DNS once and pins the IP
